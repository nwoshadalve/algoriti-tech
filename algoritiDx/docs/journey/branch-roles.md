# Branch roles

Working role model for AlgoritiDx. Roles define responsibilities; detailed permissions remain to be agreed. One person may hold multiple roles and work at multiple assigned branches.

| Role | Responsibilities |
| --- | --- |
| Branch manager | Monitor operations, manage staff assignments, review collections, and approve permitted discounts or refunds |
| Receptionist | Register patients, create test orders, schedule examinations, and provide service information |
| Cashier | Collect payments, issue receipts, track dues, and process authorized refunds |
| Sample collector | Verify patient identity, collect and label samples, and record collection or handover |
| Lab technologist | Receive samples, record processing status, enter results, and flag issues for review |
| Reporting doctor / authorized reviewer | Review findings, approve reports within their authorized scope, and issue controlled amendments |
| Imaging staff | Schedule and record imaging examinations, track completion, and prepare findings where authorized |
| Report delivery staff | Check report readiness, verify the recipient, and record delivery of approved reports |

## Permission boundaries

- Access is limited to assigned branches and permitted actions.
- Payment collection does not automatically allow discounts or refunds.
- Result entry does not automatically allow final report approval.
- Branch management does not automatically allow clinical report approval.
- Approved or delivered reports require a recorded amendment process; they must not be silently overwritten.
- Combining roles must not bypass required approval rules.

## Small-center example

One employee may hold Receptionist, Cashier, and Report Delivery roles. Separate accounts identify each employee even when responsibilities overlap.
