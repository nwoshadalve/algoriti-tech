**Online:** Choose monthly billing for a lower initial payment, or annual billing to save **৳6,000 for the first branch** and **৳4,000 per additional branch**. Hosting, standard upgrades, cloud backups, and defined support are included.

**Online + Offline:** Your **৳50,000 first-branch purchase** (৳35,000 per additional branch) includes local software, setup, training, and the first year of cloud service and upgrades. After year one:

- **Keep working locally:** no mandatory renewal.
- **Keep cloud access and branch synchronization:** optional **৳20,000/year for the first branch + ৳15,000/year per additional branch**.
- **Receive new local software upgrades:** optional annual upgrade coverage, priced before launch. Cloud renewal does not include this coverage.

## Growing to more branches

¹ **Proposed policy: no fixed branch-count limit in either plan.** Start with one branch and add more as you grow; each additional branch is charged at the discounted rate. A branch is a separate operating location within the same organization, not a counter or department. Separate businesses require separate base plans. Capacity and rollout requirements are confirmed for your organization before purchase. This is not a promise of unlimited server capacity.

For three branches:

- **Online:** ৳7,000/month, or ৳70,000/year, plus ৳30,000 one-time setup.
- **Online + Offline:** ৳120,000 upfront, including setup and first-year cloud and upgrades at all three branches. Optional cloud renewal from year two: ৳50,000/year. Local upgrade coverage is separate.

## Good to know

- Your patient data belongs to you.
- Hardware, internet, SMS, migration, custom work, integrations, extra training, and on-site visits are extra unless included in your quotation.
- Local work needs working power, a local server, and LAN. Cross-branch updates wait for reconnection during internet outages.
- Cloud synchronization requires a supported local version. Any paid upgrade requirement is explained before cloud renewal.
- Final pricing, upgrade fees, support hours, backup and recovery commitments, taxes, and cancellation/export terms are confirmed before purchase.
