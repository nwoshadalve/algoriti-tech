# AlgoritiDx

Diagnostic center operations software by Algoriti Tech.

**Status:** Planning and discovery. AlgoritiDx is a separate product from AlgoritiQ, intended for a PC/local-server setup serving diagnostic center staff over a local network. Application implementation has not started.

## Initial direction

Candidate workflows include patient registration, test orders, billing and receipts, sample tracking, and report delivery status. Scope and architecture will be confirmed through diagnostic center interviews and a pilot.

Patient data stays separate from AlgoritiQ by default. Any future referral integration requires an appropriate patient-authorized sharing workflow.
